# douyin-mcp 新手教程：只要会给 Agent 下指令

这份教程给第一次接触开源、编程、MCP 的用户看。你不需要理解代码，也不需要自己一条条敲命令。大部分事情交给 Agent 做，你只负责授权、扫码登录、确认风险。

## 你需要准备什么

- 一台 Windows 或 macOS 电脑
- Google Chrome 浏览器
- 一个你自己的抖音创作者账号
- 一个支持 MCP 和终端操作的 Agent，例如 Codex、Claude Code、Cursor、Kiro、Windsurf 等

> 只使用你自己有权访问的账号和数据。`douyin-mcp` 是非官方社区工具，使用前需要确认平台风险。

## 第一步：把一句话发给 Agent

把下面这句话复制给你的 Agent：

```text
帮我克隆并安装配置 https://github.com/Kuhakucai/douyin-mcp.git 项目
```

接下来让 Agent 自己阅读 README、检查环境、安装依赖、运行诊断、写入 MCP 配置、打开 Chrome 登录、同步数据。你不需要自己找命令，也不需要自己改配置文件。

首次安装默认不要启用视频文案功能，也不要安装 FFmpeg、ASR 模型或额外系统软件。只有你之后明确说“启用视频文案”时，再让 Agent 单独说明下载量、磁盘占用和风险，并在你确认后执行。

## 第二步：你只需要做三件事

1. Agent 提醒有平台风险时，你确认是否继续。
2. Agent 打开 Chrome 登录窗口时，你用自己的抖音账号扫码。
3. 登录成功后，保持这个专用 Chrome 打开，不要切换账号、不要手动乱点页面。

其它事情都让 Agent 处理。

## 安装成功后，可以这样问 Agent

```text
帮我看看最近 20 条作品，哪几条数据最好？原因是什么？
```

```text
按播放量、点赞率、评论率、涨粉效果，帮我找出表现异常好的视频。
```

```text
帮我总结最近表现最差的 5 条作品，给出下次选题和标题优化建议。
```

```text
把最近 30 条作品按选题类型分组，告诉我哪类内容更值得继续做。
```

```text
导出最近作品数据，给我一份适合复盘的表格。
```

## 如果 Agent 卡住了，把这段话发给它

```text
请你不要让我自己排查。请按顺序检查：

1. 当前是否在 douyin-mcp 项目目录。
2. .venv 是否存在。
3. douyin-mcp doctor 是否 ready=true。
4. 是否已经执行 acknowledge-platform-risk --yes。
5. MCP 客户端配置是否写入了 init 输出的 mcp_config。
6. 专用 Chrome 是否还开着，是否登录的是我的创作者账号。
7. 如果登录过期，请重新运行 login --timeout 180，让我扫码。

检查完成后，请用普通用户能听懂的话告诉我问题在哪里，以及你下一步准备怎么修。
```

## 需要视频文案时再启用

首次安装默认只同步创作者数据，不启用视频音轨文案。等你确实需要分析“视频里具体讲了什么”时，再发这段：

```text
请为 douyin-mcp 启用视频文案功能。启用前先告诉我需要安装什么、下载多大、占用多少磁盘、会不会很慢、有什么风险。等我确认后再执行。
```

## 给新手的判断标准

安装完成后，你不需要记住任何命令。只要 Agent 能回答这些问题，就说明已经可以开始使用：

- 最近同步了多少条作品？
- 最近 20 条作品里哪几条表现最好？
- 哪些字段有缺失，缺失原因是什么？
- 当前登录是否有效？
- 数据是什么时间同步的？

如果这些问题答不上来，让 Agent 先修复安装、登录或同步状态，再做内容分析。
